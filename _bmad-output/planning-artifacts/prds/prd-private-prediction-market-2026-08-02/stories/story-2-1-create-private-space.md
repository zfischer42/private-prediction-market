# Story 2.1: Create a private space

As an organizer,
I want to create a private space with a name,
So that I can organize bets for a specific group of friends.

**Acceptance Criteria:**
- A signed-in user can create a new space.
- The creator becomes the organizer of the space.
- The new space appears in the creator’s workspace immediately.
