- (decision) Monorepo boundary is apps/web, apps/api, packages/*, and supabase/ to keep browser, server, and data concerns separate.
- (decision) The web app may use Supabase for auth/session bootstrap, but all domain reads and writes go through the Fastify API.
- (decision) Supabase is the system of record for identity and domain data; the API is the only writer of domain state.
- (decision) Offline behavior is read-only first; mutation paths require a live network connection.
- (version) Node.js target is 22.x LTS for the workspace and API runtime.
- (version) pnpm is the workspace package manager, pinned on the 10.x line.
- (question) Exact deploy hosts for web and API are deferred; only the separate-service topology is fixed.
- (event) spine finalized
